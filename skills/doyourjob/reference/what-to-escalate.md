# What to Escalate

Use this file when classification, ownership, or decision order remains unclear. Do not draft options until the sort is complete.

## Confirm that a judgment remains

The one-decision rule governs judgment calls, not factual retrieval. Keep any item that a document, observation, measurement, policy, or known fact could settle in **Investigate**.

Reject these false classifications before testing ownership:

| Trap | Corrective test |
|---|---|
| **Unfinished investigation presented as escalation** | Would one bounded check settle it? Perform that check. |
| **False fork** | Does an option sacrifice nothing material? It probably dominates and belongs in **Decide**. |
| **Convention presented as your call** | Does the default become a customer-visible name, partner format, policy, or promise? If not, apply it; if so, find the owner. |
| **Reversible choice that later becomes load-bearing** | Measure reversal cost when the owner would discover the choice, not only today. |

## Establish ownership

Escalate only when at least one reason remains after investigation:

| Reason | Ownership test |
|---|---|
| **Value** | Defensible outcomes remain, and the choice expresses what matters more. |
| **Risk appetite** | Likelihood and damage are known, but acceptable exposure is not yours to set. |
| **Resources** | The choice spends someone else's money, people, attention, or calendar. |
| **Authority** | The choice is outward-facing, hard to reverse, or commits someone's name to another party. |

Name the applicable reason.

## Select one determining decision

1. Write each genuine judgment on one line.
2. Mark when one answer changes another judgment's available options.
3. Ask the upstream judgment with no unresolved prerequisite; name downstream judgments only as a queue.
4. If several independent judgments remain, prioritize by option expiry, blocked work, reversal cost, then blast radius.

Do not invent an umbrella question for independent choices. If dependencies form a cycle, restate the shared constraint or value; it is usually the real decision.

## Confirm the actual owner

When the owner is someone other than the current user:

1. prepare the complete decision block for that owner;
2. ask the current user only to route it or identify the owner;
3. stop before any unresolved commitment.

## Handle a moved frame

When investigation reveals a decision above the question asked:

1. answer the original question;
2. name the higher decision and the evidence that makes it real;
3. state how the original answer changes under each resolution;
4. ask whether to settle the higher decision first.

## Handle no response

If no answer arrives, continue only authorized, reversible work that pre-commits no option. Stop before the commitment. Apply a default only when the owner previously authorized both the default and its trigger.
